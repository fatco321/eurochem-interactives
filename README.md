Для «Принимаем смену» задайте iframe высоту 760 px и разрешите звук и полноэкранный режим.

```html
<iframe src="https://fatco321.github.io/eurochem-interactives/shift-handover/index.html"
  title="Тренажёр «Принимаем смену»" width="100%" height="760"
  allow="autoplay; fullscreen" allowfullscreen></iframe>
```

Остальные интерактивы отправляют высоту родительской странице сообщением `lesson-reference-height`.
